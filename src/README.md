# Source Code Implementations: Model Synthesis Repository

This directory houses the synthesized source code modules generated by the frontier Large Language Models under evaluation (**GPT-4**, **Claude 4.6 Opus**, and **Gemini 3.1 Pro**). The implementations are structured across two comparative methodological tracks and partitioned into distinct enterprise e-commerce transactional domains.

---

## 1. Directory Structure

```text
src/
├── method_1_baseline/         # Baseline NLP Track (Unconstrained Natural Language Prompts)
│   ├── checkout/              # Multi-step checkout, payment gateway & tax calculation
│   ├── promotions/            # Coupon codes, tiered discounts & cart-level promotions
│   └── shopping_cart/         # Core cart state, BVA quantity limits & quote persistence
│
├── method_2_sdd/              # SDD Approach Track (Gherkin/BDD Given-When-Then Prompts)
│   ├── checkout/              # Deterministic payment states & idempotent progression

│   └── shopping_cart/         # Strict BVA clamping, session invalidation & deficit handling
│
